# stm32-smart-car

基于 STM32F103C8T6 的蓝牙循迹避障智能小车。

## 功能

- **蓝牙遥控**：手机 APP 通过 JDY-31 蓝牙模块发送指令，控制小车前进/后退/转向。
- **避障**：HC-SR04 超声波测距。当前方障碍物距离 ≤ 35cm 时触发：先停车，转动舵机分别测量左、右两侧距离，先向后退让，再向空间较大的一侧转向绕行。
- **循迹**：四路灰度传感器识别黑线，通过左右轮差速实现直线行驶与转向（两路同时压线→直行，单侧压线→差速转向）；直角弯道通过原地旋转直到重新找到线；十字/岔路口保持直行通过。
- **OLED 显示**：实时显示蓝牙接收值、超声波距离和四路循迹传感器的状态。

## 硬件

| 模块 | 型号 |
| --- | --- |
| 主控 | STM32F103C8T6（Cortex-M3） |
| 电机驱动 | L298N |
| 超声波 | HC-SR04 |
| 舵机 | SG90 |
| 循迹 | 四路灰度传感器 |
| 蓝牙 | JDY-31 |
| 显示 | 0.96 寸 OLED（软件 IIC） |

## 引脚分配

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| 电机 PWM | PA6 / PA7 | TIM3_CH1（右）/ TIM3_CH2（左）|
| 电机方向 | PB5 / PB6 / PB7 / PB8 | L298N IN1~IN4 |
| 舵机 PWM | PA0 | TIM2_CH1，50Hz |
| 超声波 | PA4 / PA5 | Trig / Echo（TIM4 计时）|
| 循迹 | PB0 / PB1 / PB10 / PB11 | X1 / X2 / X3 / X4，低电平为检测到黑线 |
| 蓝牙 | PA9 / PA10 | USART1 TX / RX，9600 波特率 |
| OLED | PA11 / PA12 | 软件 IIC，SCL / SDA |

## 蓝牙指令

| 指令 | 功能 |
| --- | --- |
| `0x00` | 停车 |
| `0x01` | 前进 |
| `0x02` | 后退 |
| `0x03` | 左转 |
| `0x04` | 右转 |
| `0x05` | 避障模式 |
| `0x06` | 循迹模式 |

## 工程结构

```
├── User/           main.c（主逻辑）、mycontrol.c（避障与循迹）
├── HARDWARE/       各外设驱动
│   ├── LED/  MOTOR/  TIME/      LED、电机、TIM3 PWM
│   ├── OLED/                    0.96 寸 OLED 驱动
│   ├── Servo/                   舵机
│   ├── HCSR04/                  超声波
│   ├── TRACE/                   四路循迹
│   └── USART/                   蓝牙串口
├── System/         延时函数
├── Library/        STM32F10x 标准外设库
├── Start/          启动文件与 CMSIS
└── Project.uvprojx Keil MDK 工程文件
```

## 编译与烧录

1. 使用 **Keil MDK 5** 打开 `Project.uvprojx`（编译器 ARM Compiler 5）。
2. 编译后通过 ST-Link / USB 转 TTL 烧录到 STM32F103C8T6。
