# stm32-smart-car

基于 STM32F103C8T6 的蓝牙循迹避障智能小车。

## 功能

- **蓝牙遥控**：手机 APP 通过 JDY-31 蓝牙模块发送指令，控制小车前进/后退/转向。
- **避障**：HC-SR04 超声波测距。当前方障碍物距离 ≤ 35cm 时触发：先停车，转动舵机分别测量左、右两侧距离，先向后退让，再向空间较大的一侧转向绕行。
- **循迹**：四路灰度传感器识别黑线，通过左右轮差速实现直线行驶与转向（两路同时压线→直行，单侧压线→差速转向）；直角弯道通过原地旋转直到重新找到线；十字/岔路口保持直行通过。
- **OLED 显示**：实时显示蓝牙接收值、超声波距离和四路循迹传感器的状态。
- **手势遥控**：电脑摄像头（MediaPipe 官方预训练模型）识别握拳 / 张开手掌，通过蓝牙控制左转 / 右转，无手或无法确定时停车。带 **500ms 心跳超时保护**，电脑崩溃或蓝牙断开时小车自动停车。详见 [`pc_controller/README.md`](pc_controller/README.md)。

## 硬件

| 模块 | 型号 |
| --- | --- |
| 主控 | STM32F103C8T6（Cortex-M3） |
| 电机驱动 | L298N |
| 超声波 | HC-SR04 |
| 舵机 | SG90 |
| 循迹 | 四路灰度传感器 |
| 蓝牙 | JDY-31 |
| 显示 | 0.96 寸 OLED（软件 IIC） |

## 引脚分配

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| 电机 PWM | PA6 / PA7 | TIM3_CH1（右）/ TIM3_CH2（左）|
| 电机方向 | PB5 / PB6 / PB7 / PB8 | L298N IN1~IN4 |
| 舵机 PWM | PA0 | TIM2_CH1，50Hz |
| 超声波 | PA4 / PA5 | Trig / Echo（TIM4 计时）|
| 循迹 | PB0 / PB1 / PB10 / PB11 | X1 / X2 / X3 / X4，低电平为检测到黑线 |
| 蓝牙 | PA9 / PA10 | USART1 TX / RX，9600 波特率 |
| OLED | PA11 / PA12 | 软件 IIC，SCL / SDA |

## 蓝牙指令

| 指令 | 功能 |
| --- | --- |
| `0x00` | 停车 |
| `0x01` | 前进 |
| `0x02` | 后退 |
| `0x03` | 左转 |
| `0x04` | 右转 |
| `0x05` | 避障模式 |
| `0x06` | 循迹模式 |
| `0x10` | **进入手势遥控模式**（电脑端用）|
| `0x11` | **退出手势遥控模式**（电脑端用）|

`0x10` / `0x11` 是新增的模式控制字节，原本未被占用，不影响手机 APP 的
`0x00`~`0x06`。手势遥控模式下转向复用 `0x03` / `0x04`，停车复用 `0x00`。

发送的是**原始字节**，不是字符串 `"0x03"`，也不是字符 `"3"`。

## 手势遥控（STM32 端行为）

| 动作 | 行为 |
| --- | --- |
| 收到 `0x10` | 立即停车，进入手势遥控模式；此后手机遥控/循迹/避障暂不响应 |
| 模式内收到 `0x00`/`0x03`/`0x04` | 刷新心跳时间戳并执行（电脑约每 100ms 发一次）|
| **超过 500ms 没收到有效指令** | 强制停车。模式保持不变，OLED 显示 `[TMO]` |
| 超时后重新收到指令 | 自动恢复受控（电脑端默认继续发停车，需重新做手势才会转向）|
| 收到 `0x11` | 停车并退出模式，控制权交回手机遥控/循迹/避障 |
| 掉电/复位 | 回到普通模式（`RxData = 0x00`），停车 |

超时计时用 **TIM1 的 1ms 更新中断**做独立时间基准：TIM2（舵机 PWM）、
TIM3（电机 PWM）、TIM4（超声波 Echo 计时）和 SysTick（被 `Delay_us` 直接
改写做忙等）都不能动，TIM1 原本未被使用，且只用更新中断、不占用引脚。
计时完全由硬件中断驱动，不依赖主循环执行速度。

OLED 第二行（`U1RX:` 那一行）右侧显示模式状态：

| 显示 | 含义 |
| --- | --- |
| `[GES]` | 手势遥控模式，正常受控中 |
| `[TMO]` | 手势遥控模式，但已超时停车（电脑掉线或崩溃）|
| `[---]` | 未进入手势模式，手机遥控 / 循迹 / 避障正常 |

## 工程结构

```
├── User/           main.c（主逻辑）、mycontrol.c（避障、循迹、手势遥控模式）
├── HARDWARE/       各外设驱动
│   ├── LED/  MOTOR/  TIME/      LED、电机、TIM3 PWM
│   ├── OLED/                    0.96 寸 OLED 驱动
│   ├── Servo/                   舵机
│   ├── HCSR04/                  超声波
│   ├── TRACE/                   四路循迹
│   └── USART/                   蓝牙串口
├── System/         延时函数
├── Library/        STM32F10x 标准外设库
├── Start/          启动文件与 CMSIS
├── pc_controller/  电脑端手势遥控（Python + MediaPipe）
└── Project.uvprojx Keil MDK 工程文件
```

STM32 端的手势模式代码放在既有的 `User/mycontrol.c` / `mycontrol.h` 里
（这两个文件本来就在 Keil 工程中），因此**不需要修改 `Project.uvprojx`**。
改动只涉及 4 个文件：`User/mycontrol.c`、`User/mycontrol.h`、
`User/main.c`、`HARDWARE/USART/USART1.c`。

## 编译与烧录

1. 使用 **Keil MDK 5** 打开 `Project.uvprojx`（编译器 ARM Compiler 5）。
2. 编译后通过 ST-Link / USB 转 TTL 烧录到 STM32F103C8T6。
